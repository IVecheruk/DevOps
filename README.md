| Задание | Содержание |

```bash
git clone https://github.com/IVecheruk/DevOps.git
cd DevOps
```

Откройте отчёт нужного задания: в нём указаны установка и команда запуска. Для заданий 2.1, 2.2 и 2.4 достаточно Python 3.10+; для 2.3 нужны пакеты из его `requirements.txt`.
