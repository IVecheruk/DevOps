# DevOps

Учебный репозиторий с лабораторными работами и практическими заданиями по DevOps. Для каждого задания выделена отдельная папка с Markdown-отчётом, исходным кодом и необходимыми материалами.

## Задания

| Задание | Тема | Материалы |
| --- | --- | --- |
| 2.1 | Скрипты Python для автоматизации управления архитектурой: анализ логов Nginx и оповещения в Telegram | [Отчёт, код и инструкция запуска](labs/lab-2.1/README.md) |
| 2.2 | Проверка доступности сайтов из `link.txt` с сохранением результата в `report.txt` | [Отчёт, код и инструкция запуска](labs/lab-2.2/README.md) |
| 2.3 | Поиск текущего официального курса валюты на странице Банка России | [Отчёт, код и инструкция запуска](labs/lab-2.3/README.md) |

## Структура репозитория

```text
DevOps/
├── README.md                  # оглавление заданий
├── .gitignore                 # общие исключения Git
└── labs/
    ├── lab-2.1/
    │   ├── README.md          # отчёт по заданию 2.1
    │   ├── analyze_logs.py    # скрипт анализа логов
    │   ├── requirements.txt   # необязательная зависимость для Telegram
    │   ├── examples/
    │   │   └── access.log     # учебный лог
    │   └── tests/
    │       └── test_analyze_logs.py
    ├── lab-2.2/
    │   ├── README.md          # отчёт по заданию 2.2
    │   ├── check_links.py     # проверка доступности сайтов
    │   ├── link.txt           # список адресов
    │   ├── report.txt         # результат проверки
    │   └── tests/
    │       └── test_check_links.py
    └── lab-2.3/
        ├── README.md          # отчёт по заданию 2.3
        ├── currency_rate.py   # получение курса с сайта Банка России
        ├── requirements.txt  # requests и beautifulsoup4
        ├── examples/
        │   └── cbr_page.html  # учебный HTML-фрагмент для тестов
        └── tests/
            └── test_currency_rate.py
```

Новые задания добавляются в `labs/lab-<номер>/` и в таблицу выше. Их зависимости, примеры и тесты хранятся внутри соответствующего задания. Общие настройки репозитория находятся в корне.

## Клонирование

```bash
git clone https://github.com/IVecheruk/DevOps.git
cd DevOps
```

Далее откройте инструкцию нужного задания из оглавления.

## Быстрый запуск задания 2.1

Нужен Python 3.10 или новее. Из корня репозитория:

```bash
cd labs/lab-2.1
python analyze_logs.py
python -m unittest discover -s tests -v
```

На Linux/macOS при необходимости замените `python` на `python3`, на Windows можно использовать `py -3`.

Локальный анализ работает без установки пакетов, Nginx и Telegram-токена. Подключение Telegram и анализ собственного лога описаны в [отчёте задания 2.1](labs/lab-2.1/README.md).

## Быстрый запуск задания 2.2

Из корня репозитория:

```bash
cd labs/lab-2.2
python check_links.py
python -m unittest discover -s tests -v
```

Скрипт читает `link.txt` и создаёт `report.txt` со строками `адрес -> Ok` или `адрес -> Error`. Для внешних сайтов нужен интернет; тесты работают на локальном HTTP-сервере. Дополнительные пакеты не требуются. Подробности — в [отчёте задания 2.2](labs/lab-2.2/README.md).

## Быстрый запуск задания 2.3

Из корня репозитория:

```bash
cd labs/lab-2.3
python -m pip install -r requirements.txt
python currency_rate.py
```

Скрипт показывает дату и установленный Банком России курс USD к рублю. Страница, структура таблицы и объяснение кода приведены в [отчёте задания 2.3](labs/lab-2.3/README.md).
