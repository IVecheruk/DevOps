# Задание 2.2 — доступность сайтов

[← К списку заданий](../../README.md)

## Цель

Прочитать сайты из [link.txt](link.txt) и записать в [report.txt](report.txt) строки вида `адрес -> Ok` или `адрес -> Error`.

## Как работает

[Скрипт](check_links.py) открывает каждый адрес через `urllib.request.urlopen()`. HTTP-ответ 2xx даёт `Ok`; ошибка запроса или другой статус — `Error`. Пустые строки пропускаются. `with` закрывает файлы и HTTP-ответ, а режим `"w"` перезаписывает отчёт при каждом запуске.

Используется только стандартная библиотека Python. Нужны Python 3.10+ и интернет для проверки внешних сайтов.

```bash
git clone https://github.com/IVecheruk/DevOps.git
cd DevOps/labs/lab-2.2
python check_links.py
```

Запускайте скрипт из папки задания. В `link.txt` указывайте по одному полному адресу с `https://` или `http://` на строку. После запуска откройте `report.txt`; в терминал скрипт ничего не выводит.

Пример результата на момент проверки:

```text
https://example.com -> Ok
https://www.python.org -> Ok
https://example.invalid -> Error
```

## Вывод

Задание выполнено: адреса считываются из файла, а результаты HTTP-проверки сохраняются в заданном формате. Доступность внешних сайтов может меняться.
