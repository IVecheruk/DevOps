# Задание 2.3 — курс валюты

[← К списку заданий](../../README.md)

## Цель

Получить действующий официальный курс USD к рублю с [страницы Банка России](https://www.cbr.ru/currency_base/daily/).

## Как работает

[Скрипт](currency_rate.py) загружает HTML через `requests.get()`. `BeautifulSoup` находит таблицу с классом `data`, а `re.search()` — дату в заголовке. В строке таблицы код валюты находится во второй ячейке (`cells[1]`), число единиц — в третьей (`cells[2]`), курс — в пятой (`cells[4]`). Это реальная структура сайта, поэтому номера ячеек отличаются от учебного примера с двумя колонками.

`requests` и `beautifulsoup4` перечислены в [requirements.txt](requirements.txt). Нужны Python 3.10+ и интернет.

```bash
git clone https://github.com/IVecheruk/DevOps.git
cd DevOps/labs/lab-2.3
python -m pip install -r requirements.txt
python currency_rate.py
```

Пример фактического вывода 26.09.2026:

```text
26.09.2026: 1 USD = 84,3414 RUB
```

Чтобы искать другую валюту, измените константу `CURRENCY` в скрипте. Столбец «Единиц» важен: на сайте курс некоторых валют указан, например, за 100 единиц.

## Вывод

Парсер извлекает курс и дату из реальной HTML-таблицы. Это официальный курс на опубликованную дату; число и структура страницы могут измениться при следующих запусках.
