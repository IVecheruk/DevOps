# Лабораторная работа 2.3

[← Все задания](../../README.md)

**Тема:** поиск курса валюты на веб-странице с помощью Python.

**Условие:** написать скрипт, который загружает страницу сайта, находит на ней действующий курс валюты и выводит его. Пример из задания требуется адаптировать к структуре реального сайта.

**Репозиторий:** [IVecheruk/DevOps](https://github.com/IVecheruk/DevOps). **Страница задания:** [labs/lab-2.3](https://github.com/IVecheruk/DevOps/tree/main/labs/lab-2.3).

## 1. Цель работы

Научиться получать HTML-страницу, находить нужную строку таблицы и извлекать из неё дату, название валюты, количество единиц и курс.

## 2. Теоретические сведения

Источник данных — [официальная страница Банка России с ежедневными курсами](https://www.cbr.ru/currency_base/daily/). На ней указаны курсы иностранных валют к рублю и дата, **с которой они установлены**. Это действующий официальный курс на опубликованную дату, а не цена валюты в обменном пункте или котировка, меняющаяся каждую секунду.

Используются следующие библиотеки:

| Библиотека | Для чего нужна |
| --- | --- |
| `requests` | `get()` загружает страницу, `raise_for_status()` сообщает об ошибочном HTTP-ответе |
| `bs4` (`beautifulsoup4`) | `BeautifulSoup` разбирает HTML, `find()` и `find_all()` ищут элементы, `get_text()` извлекает текст |
| `re` | Регулярное выражение находит дату вида `26.09.2026` в заголовке страницы; входит в стандартную библиотеку Python |

Документация: [Requests Quickstart](https://requests.readthedocs.io/en/latest/user/quickstart/), [Beautiful Soup](https://www.crummy.com/software/BeautifulSoup/bs4/doc/).

На реальной странице таблица имеет HTML-класс `data`. Каждая строка курса содержит **пять** ячеек:

| Индекс ячейки | Заголовок | Пример для USD |
| ---: | --- | --- |
| `0` | Цифровой код | `840` |
| `1` | Буквенный код | `USD` |
| `2` | Единиц | `1` |
| `3` | Валюта | `Доллар США` |
| `4` | Курс | `84,3414` |

Именно поэтому в [скрипте](currency_rate.py) код валюты читается из `cells[1]`, число единиц — из `cells[2]`, а курс — из `cells[4]`. В примере задания предполагалась таблица из двух колонок, но у выбранного сайта другая структура. Валюта для поиска задана константой `CURRENCY = "USD"`.

### Установка и запуск

Нужны Git, Python 3.10 или новее и доступ к интернету. После клонирования выполните:

```bash
git clone https://github.com/IVecheruk/DevOps.git
cd DevOps/labs/lab-2.3
python -m pip install -r requirements.txt
python currency_rate.py
```

Если репозиторий уже клонирован, обновите его командой `git pull` из корня и перейдите в `labs/lab-2.3`. На Linux/macOS при необходимости замените `python` на `python3`, на Windows можно использовать `py -3`.

Скрипт запускается без аргументов и выводит одну строку в терминал. Файл с курсом не создаётся: это не требуется условием задания.

### Алгоритм и объяснение для защиты

1. `requests.get(URL, timeout=10)` загружает страницу. Число `10` ограничивает ожидание отдельных сетевых операций в секундах.
2. `response.raise_for_status()` прерывает выполнение при ошибке HTTP, например 404 или 500.
3. `BeautifulSoup(response.text, "html.parser")` преобразует текст HTML в объект, по которому удобно искать теги.
4. `soup.find("h2")` находит заголовок с датой. `re.search(...)` извлекает дату в формате `дд.мм.гггг`.
5. `soup.find("table", class_="data")` находит таблицу курсов. Цикл проходит по её строкам `<tr>` и берёт ячейки `<td>`.
6. Условие `cells[1].get_text(strip=True) == CURRENCY` выбирает строку USD. Проверка `len(cells) >= 5` не позволяет обращаться к отсутствующим ячейкам; строка с заголовками `<th>` пропускается.
7. Из выбранной строки считываются число единиц и курс. `print()` выводит дату и результат, а `break` прекращает поиск.
8. Если дата, таблица или валюта отсутствуют, скрипт сообщает об ошибке. Это помогает заметить изменение разметки сайта вместо вывода неправильного курса.

Если преподаватель спросит, почему курс не всегда относится к одной единице валюты: у Банка России есть отдельная колонка **«Единиц»**. Например, курс JPY может быть указан за 100 иен. Скрипт выводит это число рядом с валютой, поэтому не искажает значение.

## 4. Результаты

При проверке **26 сентября 2026 года** скрипт получил реальную страницу Банка России и вывел:

```text
26.09.2026: 1 USD = 84,3414 RUB
```

Число и дата соответствовали [опубликованной таблице Банка России](https://www.cbr.ru/currency_base/daily/) на момент проверки. При следующем запуске программа вновь загружает страницу; результат может измениться после публикации нового курса.

Для проверки разбора HTML без сети используйте:

```bash
python -m unittest discover -s tests -v
```

**Результат: 3 теста, `OK`.** Проверены поиск USD, даты, числа единиц и курса, а также сообщения при отсутствии таблицы или нужной валюты.

## 5. Выводы

Пример из задания адаптирован к реальной странице: найден официальный курс доллара США к рублю с учётом даты и числа единиц. В работе использованы HTTP-запрос, разбор HTML, поиск таблицы и обработка отсутствующих данных.

Скрипт зависит от доступности сайта и его HTML-структуры. Если Банк России изменит разметку, может потребоваться обновить поиск заголовка, таблицы или колонок. Курс является официальным значением на опубликованную дату; он не отражает цену покупки или продажи наличной валюты.
