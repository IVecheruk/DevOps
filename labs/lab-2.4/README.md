# Задание 2.4 — изменения веб-страниц

[← К списку заданий](../../README.md)

## Цель

Обойти адреса из [link.txt](link.txt), сравнить содержимое страниц с прошлым успешным обходом и записать результат в [report.txt](report.txt).

## Как работает

[Скрипт](check_changes.py) загружает страницу через `urlopen()` и вычисляет SHA-256-хеш её байтов с помощью `hashlib`. Хеши сохраняются в `hashes.json`. При следующем запуске скрипт сравнивает новый хеш с сохранённым. `json` нужен для чтения и записи этого файла; сторонние пакеты не требуются.

| Статус | Значение |
| --- | --- |
| `NEW` | Первый успешный обход адреса |
| `OK` | Хеш совпал |
| `CHANGED` | Хеш изменился |
| `ERROR` | Страницу не удалось получить; прежний хеш сохраняется |

Нужны Python 3.10+ и интернет для внешних сайтов. Запускайте из папки задания:

```bash
git clone https://github.com/IVecheruk/DevOps.git
cd DevOps/labs/lab-2.4
python check_changes.py
python check_changes.py
```

Первый запуск создаёт `hashes.json`. Второй покажет `OK`, если страница не изменилась. Файл `hashes.json` не хранится в Git, поэтому после клонирования сравнение начинается с чистого состояния.

Пример [отчёта](report.txt) после второго обхода:

```text
https://example.com -> OK
https://example.invalid -> ERROR
```

## Вывод

Сравнение хешей показывает изменение полученных байтов страницы. Скрипт не определяет, какая именно часть HTML поменялась; даже небольшое динамическое содержимое может дать `CHANGED`.
